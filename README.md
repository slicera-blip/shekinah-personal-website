# JavaScript Programming Activities
- **Coure:CS-1130 Introduction to Computing SEM 1 2026 GERALDE**

  An interactive and user-friendly website created using HTML, CSS, and JavaScript. It features four programming assignments that showcase fundamental programming concepts through various calculators and basic applications.

# Tasked Assignment
  
**1. Conversion Calculator** – Performs unit conversions, including Celsius to Fahrenheit, Fahrenheit to Celsius, meters to feet, and feet to meters.

**2. Income Tax Calculator** – Determines the applicable income tax using the Philippine tax bracket system.

**3. Factorial, Sum, and Average Calculator** – Computes the factorial, total sum, and average of the first N natural numbers using different looping structures: while, do-while, and for loops.

**4. Simple Payroll System** – Allows users to add and delete employee records while calculating their gross and net pay based on days worked, daily rate, and deductions.
